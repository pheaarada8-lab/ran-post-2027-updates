# Ran Post 2027 — GitHub Update Repository

This repository is the public update feed for Ran Post 2027.

## First setup
1. Upload the contents of this folder to the GitHub repository `ran-post-2027-updates`.
2. Commit the files to the `main` branch.
3. Create a GitHub Release when a tested Windows application ZIP is ready.
4. Attach the Windows application ZIP to that Release.

## Important
This setup package contains the update-feed starter files only. It is NOT the Windows application.
Do not publish a release until the actual, tested Ran Post 2027 Windows application ZIP is available.

## Update feed
The app's updater should read `update.json` from the raw URL of this repository's `main` branch.
